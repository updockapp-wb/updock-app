# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: modal-stacking-under-vaul-drawer — Any global overlay/modal rendered as a normal
      React child of `#root` (which has `isolation: isolate`, pre-existing in `src/index.css`)
      gets visually trapped BEHIND any open Vaul drawer that uses `shouldScaleBackground`
      (e.g. `SpotDetail.tsx`'s `Drawer.Root`), regardless of the modal's z-index. This is because
      Vaul's `Drawer.Content` portals straight to `document.body`, escaping `#root`'s isolation
      boundary, while a non-portaled modal does not. — **Structural mitigation**: `src/ui/Modal.tsx`
      now renders all 3 shapes via `createPortal(..., document.body)` (commit `497f347` on `main`).
      Any FUTURE global overlay component must follow the same pattern (portal to `document.body`)
      instead of relying on z-index alone — z-index comparisons only work within a shared stacking
      context, and `#root`'s isolation silently creates a new one for everything inside it.

**Do not proceed until all boxes are checked.**
