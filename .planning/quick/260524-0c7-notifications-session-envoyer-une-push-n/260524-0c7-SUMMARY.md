Database webhook trigger for session creation notifications, user notification preferences toggle, and same-day session conflict detection with join option.

## What Was Built

1. **Migration 007**: Adds `notif_session_enabled BOOLEAN DEFAULT true` column to profiles. Contains commented SQL for a database webhook trigger (`notify_session_created_webhook`) that fires on session INSERT and calls the Edge Function via `pg_net`.

2. **Edge Function update**: Filters notification recipients by `notif_session_enabled` preference before sending push tokens. Supports both webhook payload format (`row_to_json(NEW)` directly) and manual invocation (`{ record: ... }`).

3. **Profile notification toggle**: New toggle switch in Profile settings (visible only when push permission is granted) to enable/disable session notifications. Uses optimistic update with rollback on error.

4. **Session conflict detection**: `checkSessionConflict` in SessionsContext queries for existing non-cancelled sessions on the same spot and same calendar day. SessionForm calls this before creating and shows an amber conflict banner with the existing session details, a "Join this session" button, and a "Create anyway" button.

5. **Translations**: Added FR/EN keys for conflict message, join button, create-anyway button, notification toggle label, and notification toggle description.
