# Phase quick-260731-e56 Plan 01: Corriger les 4 petits bugs de recette Phase 4 Summary

Correction de 3 écarts UI/i18n indépendants de la recette device Phase 4 : croix de fermeture SpotDetail coupée sur nom long, description de spot rendue obligatoire dans les 3 formulaires migrés, et accents manquants sur « communauté » dans fr.json.

## What Was Built

### Task 1 — Croix de fermeture SpotDetail (commit 034dc9c)
- `src/components/SpotDetail.tsx` ligne 254 : `flex-1` → `flex-1 min-w-0` (le conteneur titre peut désormais se réduire sous sa largeur de contenu intrinsèque).
- Ligne 307 : `flex gap-2` → `flex gap-2 shrink-0` (la rangée share/favori/fermer ne se compresse jamais hors écran).
- Le `flex-wrap` existant gère le retour à la ligne du nom long ; aucun `truncate` ajouté.

### Task 2 — Description obligatoire dans les 3 formulaires (commit ed46814)
- Nouvelle clé i18n `form.error.desc_required` insérée après `form.error.name_required`, parité stricte fr/en :
  - fr : « La description du spot est obligatoire. »
  - en : « Spot description is required. »
- `AddSpotForm.tsx` (handleSubmit) : `if (!description.trim())` avant le check `desc_too_long`.
- `SpotDetail.tsx` (handleSaveEdit, édition inline) : `if (!(editForm.description || '').trim())`.
- `AdminDashboard.tsx` (handleSaveEdit) : `if (editingSpot.description.trim().length === 0)`.
- Pattern early-return répliqué exactement : `setError` traduit + `return` avant toute mutation, données saisies préservées.

### Task 3 — Accents « communauté » dans fr.json (commit e1f2308)
- `anon_profile.title` : « communaute » → « communauté ».
- `anon_profile.subtitle` : « Decouvre … communaute. » → « Découvre … communauté. ».
- `community_stats.title` : « La communaute » → « La communauté ».
- `community_stats.nav_label` : « Statistiques communaute » → « Statistiques communauté ».
- Grep `communaute` (sans accent) sur fr.json = 0 après correction.
